# DWlaptopANDandroid

Browser extensions for downloading from rule34.xxx, working on desktop Chrome / Edge / Brave / Opera **and** Kiwi Browser on Android.

## Содержимое

- [`rule34-dw-extension/`](./rule34-dw-extension) — MV3 расширение «Rule34 DW Button».
  Подробности и установка — в [README расширения](./rule34-dw-extension/README.md).

## Сборка zip-архива

```bash
cd rule34-dw-extension
zip -r ../rule34-dw-extension.zip . -x ".*"
```

В корне репозитория появится `rule34-dw-extension.zip` — его можно скинуть на телефон в Kiwi Browser или распаковать локально и подгрузить как unpacked extension.
