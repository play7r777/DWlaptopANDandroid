# Rule34 DW Button — расширение для браузера

Тихая массовая скачка оригиналов с rule34.xxx через `chrome.downloads.download({saveAs:false})` — браузер не спрашивает «куда сохранить» для каждого файла, всё валится в `Downloads/rule34/`.

## Возможности

- Кнопка **DW** в правом верхнем углу каждой миниатюры в скролл-ленте
- Круглая кнопка **DW** в правом нижнем углу на странице конкретного поста
- Sticky-панель **Solo / Multi** в верхнем правом углу ленты:
  - **Solo** — обычные кнопки DW на каждой работе
  - **Multi** — пустые квадраты-чекбоксы, тыкаешь → ставишь галочку, ещё раз → снимаешь. Снизу — кнопка **«Скачать выбранные (N)»**
- **Easy-select** — отдельная галочка в верхнем правом углу панели (и в multi-меню). Когда включена, **тапнуть можно по любому месту работы**, не целясь в маленький квадратик. На рабочем столе по hover'у работы появляется синяя рамка, на выделенных — зелёная.
- Режим **и выбранные работы** сохраняются между переходами по страницам, вкладками и перезапусками браузера (`chrome.storage.local`). Можешь натыкать 4 на одной странице, перейти на следующую, натыкать ещё 7, потом нажать «Скачать выбранные (11)» — все скачаются разом.
- **Сброс выбора только красной кнопкой** «Снять выделение». Даже после успешного скачивания работы остаются выделенными — удобно для повторов / докачивания.
- Открытые в нескольких вкладках страницы синхронизируются друг с другом — выделил во вкладке А, во вкладке Б счётчик сразу обновится.
- Качается **именно оригинал** (Original image / Original video), приоритет по качеству: video (webm/mp4) → png → jpg → gif → webp. **Никогда не качается `.php`** — есть жёсткий гард на media-расширения.
- Устойчиво к **429 / 403** ошибкам rule34: экспоненциальный бэкофф 2→30с с джиттером, до 8 ретраев, фоллбэк на JSON API через `api.rule34.xxx` (с правильным Referer'ом), персистентный кеш разрешённых URL'ов (14 дней) — повторные попытки моментальные.
- Поддержка infinite scroll (новые миниатюры подхватываются автоматически)

## Установка

### Desktop Chrome / Edge / Brave / Opera

1. Распакуй `rule34-dw-extension.zip` в любую папку
2. Открой `chrome://extensions` (или `edge://extensions` / `brave://extensions`)
3. Включи **Developer mode** (правый верхний угол)
4. Нажми **Load unpacked** → выбери распакованную папку
5. Зайди на rule34.xxx — кнопки DW появятся

### Kiwi Browser (Android)

1. Скачай zip на телефон, распакуй (любым архиватором, например ZArchiver)
2. Открой Kiwi Browser → меню → **Extensions**
3. Включи **Developer mode** → **Load**
4. Выбери папку с распакованным расширением
5. Готово

### Firefox (desktop)

WebExtensions API совместим, но MV3 в Firefox имеет нюансы со service worker'ами. Для постоянной установки нужно подписать через `addons.mozilla.org`. Для разовой загрузки:
1. `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on**
2. Выбери `manifest.json` из распакованной папки
3. (Расширение сбросится при перезапуске Firefox — это особенность temporary add-ons)

## Куда падают файлы

В подпапку `Downloads/rule34/`. Если файл с таким именем уже есть — добавляется суффикс `(1)`, `(2)`, … (`conflictAction: 'uniquify'`).

## Где это НЕ работает

- iOS Safari — у iOS-расширений нет downloads API, там только userscript-вариант остаётся актуальным
- В incognito — нужно отдельно разрешить расширение в режиме инкогнито
